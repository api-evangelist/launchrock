# Launchrock

> Launchrock is a hosted launch-page and customer-acquisition tool for early-stage
> founders. It provides a drag-and-drop WYSIWYG builder for pre-launch marketing
> pages, email capture forms, viral referral/sharing mechanics and simple survey
> questions, so a founder can stand up a "coming soon" site and collect a waitlist
> of early users before a product ships. Launchrock is operated as one product line
> of the Startups.com platform, alongside Fundable, Bizplan and Clarity.fm, and is
> bundled into the Startups Unlimited subscription. Vevo, HotelTonight and theCHIVE
> are cited as sites that launched on the platform. Launchrock was originally a
> 500 Global (500 Startups) portfolio company.

## Status

- No public API. Re-probed 2026-08-13: Launchrock publishes no developer portal,
  API reference, OpenAPI or AsyncAPI description, GraphQL schema, SDK, CLI,
  Postman collection, webhook catalog or sandbox. Probes of /api, /docs,
  /developers, /developer, /changelog and /status, and of the api., app.,
  developers., developer., docs., status. and trust. subdomains, all returned 404
  or resolved onto the generic Startups.com site cluster.
- No /.well-known/ documents, no agent card and no /llms.txt are served on
  launchrock.com. Both /.well-known/agent-card.json and the legacy
  /.well-known/agent.json return 404.
- There IS one live machine surface, and it is not for you: an internal Apollo
  GraphQL endpoint at https://www.launchrock.com/graphql backs the Startups.com
  web application. Introspection is disabled in production, GET returns 401
  "Not Allowed", and no schema, reference or authentication documentation exists
  for it. It is the app's private backend, not a developer API. Do not treat it
  as an integration point.
- No first-party client library exists in any package registry, and there is no
  Launchrock GitHub organization. The only package bearing the name is a
  third-party Ruby gem last released 2013-06-15, written against a Launchrock API
  that no longer exists; its source repository has since been deleted.
- The sitemap served at launchrock.com is the Startups.com sitemap — 13,524 URLs,
  none of them developer, API, docs, changelog or status pages.
- The Launchrock help center contains zero occurrences of the word "API"; its
  Launchrock section is DNS A-record and CNAME instructions for custom domains.
- The historic blog.launchrock.com is dead (redirects to a 404).
- Delivery is entirely through the hosted web application; collected signups are
  worked through the Launchrock dashboard and its email integration rather than
  through a programmatic interface.

## Pricing

Launchrock is not sold standalone. Its pricing page sells the Startups.com
"Startups Unlimited" bundle (Launchrock + Bizplan + Fundable + Startup
University), in three billing terms with the same feature set:

- Monthly — $29/mo
- Annual — $20.75/mo, billed $249/year (marked "Most Popular")
- Lifetime Access — $349 one-time

There is no free tier, no usage metering and no API quota.
